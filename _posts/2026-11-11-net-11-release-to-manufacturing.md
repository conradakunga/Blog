The **final release of .NET 11** has finally dropped!

You can read the full announcement [here](https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/).

The key changes are these:

- C# 15
- .NET 11
- EF Core 11
- DotnetUp tool
- ASP.NET Core 
- Blazor
- WinUI, Windows Forms, WPF

The downloads are [here](https://dotnet.microsoft.com/en-us/download/dotnet/11.0).

**Happy hacking!**
